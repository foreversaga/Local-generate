# 分段影片生成與尾幀續拍流程

本文件說明如何將較長的影片拆成多個短片段生成，例如先生成兩段各 5 秒的影片，再使用第一段的尾幀作為第二段的首幀，以提升場景、角色和動作的連貫性，最後將片段合併成一支影片。

## 流程概覽

```text
第 1 段（T2V 或 I2V，5 秒）
        ↓ 擷取最後一幀
尾幀圖片
        ↓ 作為第 2 段的首幀
第 2 段（I2V，5 秒）
        ↓
合併兩段 MP4
```

第二段應使用「圖片生影片（I2V / Image → Video）」。不要使用「尾幀生片（L2V / Last Frame → Video）」：L2V 的用途是讓生成影片在結尾抵達指定圖片，不是從該圖片向後續拍。

## 1. 規劃兩段動作

先把完整動作拆成兩段，但不要讓第一段在第 5 秒完全收尾。第一段應停在仍能自然延續的動作中間狀態，例如：

- 角色仍在跑動，而不是已經停下。
- 手正在伸向物品，而不是已完成拿取並回到靜止姿勢。
- 攝影機仍以固定方向跟拍，而不是在片尾切鏡或淡出。

接點前後應維持相同的角色外觀、服裝、場景、光線、鏡頭高度、焦段、運鏡方向與速度。

## 2. 生成第一段

在 H3 Studio 選擇適當模式：

- 沒有首圖時：使用「文字生影片（T2V）」。
- 已有角色或場景首圖時：使用「圖片生影片（I2V）」。

建議設定：

- 時長：5 秒。
- 第二段沿用相同的模型 profile、解析度、長寬比、步數及 FPS。
- 避免在結尾安排切鏡、淡出、遮黑或突然停止運鏡。

第一段提示詞範例：

> 一名穿紅色外套的年輕女子沿著雨夜街道向前奔跑，右腳落地後左腿正向前擺動，攝影機以穩定的 tracking shot 從左後方跟隨。最後她仍保持奔跑，不停下、不轉場，攝影機方向和速度保持穩定。

## 3. 擷取第一段尾幀

若介面沒有提供「擷取尾幀」功能，可使用 FFmpeg。以下命令會讀取影片最後一秒，反覆覆寫同一張圖片，最後保留實際最末幀：

```powershell
ffmpeg -sseof -1 -i part1.mp4 -map 0:v:0 -fps_mode passthrough -update 1 part1-tail.png
```

若最末幀正好有編碼模糊、淡出或明顯動態殘影，可改取結尾前約 0.1 秒的畫面：

```powershell
ffmpeg -sseof -0.1 -i part1.mp4 -frames:v 1 part1-tail.png
```

使用前先檢查 `part1-tail.png`：若角色臉部、手腳或背景已經變形，建議重新生成第一段或擷取稍早且較清楚的畫面，否則第二段可能延續該缺陷。

## 4. 使用尾幀生成第二段

在 H3 Studio 中：

1. 選擇「圖片生影片（I2V / Image → Video）」。
2. 上傳 `part1-tail.png` 作為首幀圖片。
3. 將時長設為 5 秒。
4. 沿用第一段的模型 profile、解析度、步數等生成參數。
5. 提示詞描述從首幀開始的後續發展，不要讓角色重新開始同一個動作。

I2V 提示詞應以輸入圖片作為 0.00 秒的實際首幀，依序描述「首幀錨定 → 動作接續 → 持續發展 → 結果」。例如：

> 完全延續輸入首幀中的同一人物、臉部、紅色外套、雨夜街道、燈光、攝影機高度、鏡頭方向與奔跑速度。她從首幀中的奔跑步態自然接續，左腳向前落地，右腿隨後擺動，持續沿相同方向奔跑。攝影機保持相同速度的 tracking shot，不切鏡、不跳位、不重新起步。背景透視和雨勢連續變化。

負面提示詞範例：

```text
identity drift, different clothing, scene change, camera jump, pose reset,
duplicated limbs, deformed hands, flicker, sudden lighting change,
discontinuous motion, cut, transition
```

可以先沿用第一段的 seed，但相同 seed 本身不保證連續。尾幀圖片、固定的視覺條件、連續動作描述及一致的生成參數才是主要控制手段。

## 5. 合併兩段影片

先建立 `concat.txt`，路徑建議使用正斜線：

```text
file 'C:/影片路徑/part1.mp4'
file 'C:/影片路徑/part2.mp4'
```

如果兩段的編碼、解析度、FPS、音訊格式及 time base 相同，可以直接無損拼接：

```powershell
ffmpeg -f concat -safe 0 -i concat.txt -c copy final-10s.mp4
```

如果發生時間軸、音訊或編碼不相容問題，改為重新編碼：

```powershell
ffmpeg -f concat -safe 0 -i concat.txt `
  -c:v libx264 -crf 18 -preset medium `
  -c:a aac -b:a 192k `
  -movflags +faststart final-10s.mp4
```

## 6. 接縫檢查與改善

合併後應檢查第 5 秒附近：

- 角色身分、臉部、衣服是否改變。
- 身體動作是否重置、跳位或方向相反。
- 攝影機角度、移動方向或速度是否突然改變。
- 光線、色溫、雨勢及背景物件是否閃動。
- 音訊是否中斷、重複或音量突然變化。

由於第二段首幀等於第一段尾幀，接點可能出現一幀的短暫停頓。通常不明顯；若需要更精細的結果，可在後製時移除第二段第一幀，或對接點做非常短的交叉淡化。動作快速時優先移除重複幀，慢速鏡頭則可視情況使用短交叉淡化。

## 7. 延伸至更多片段

需要 15 秒或更長影片時，重複相同流程：

```text
第 1 段尾幀 → 第 2 段 I2V
第 2 段尾幀 → 第 3 段 I2V
第 3 段尾幀 → 第 4 段 I2V
```

每次續拍都應以前一段的實際尾幀為首幀，並保存一份固定的「連貫性設定」，至少記錄：角色外觀、服裝、場景、時間與光線、鏡頭規格、運鏡方向、動作方向、模型 profile、解析度、步數及 FPS。分段越多，累積偏移越明顯，因此應在每一段完成後先檢查尾幀，再繼續下一段。
